# Southern Machinery · Radial Insertion Machine

基于 Google Drive 原始资料构建的中文响应式产品展示应用，包含产品概览、市场需求场景、采购评估、工艺导览、维护注意事项、视频资料库及原始文件入口。

## 本地运行

```bash
npm install
npm run dev
```

访问终端显示的地址。生产构建：`npm run build`，静态文件位于 `dist/`。部署到任意支持静态站点的服务即可，无需后端。

## 内容与来源

原始素材：[Google Drive 文件夹](https://drive.google.com/drive/folders/1dsodLhtRnc5hTdnCbFAfCEx0u_gnO-wi)。关键引用包括 S3000 系列说明书 2025 V2、软件操作与编程手册 2025 V2、2024 产品宣传册、S3010A 自动化方案和销售解说稿。每份资料均可在页面中打开原件。视频通过 Google Drive 预览播放，受源文件共享权限及浏览器第三方内容策略影响；打不开时可点击“打开原文件”。

**资料边界：** 2024 宣传册与 2025 说明书对部分指标存在差异；页面避免将不一致的速度或投资回报表述为保证值。市场部分不包含未经提供材料验证的行业规模数字。操作与维护栏目为原厂材料导览，不替代对应机型的完整安全培训及维修手册。
